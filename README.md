# Agent Memory Template

可复用的 agent 记忆库模板：文件系统结构 + 写入规范，开箱即用，替换占位内容即可。

## 架构

```
memory/
├── AGENTS.md   方法论：元规则章（记忆规范自包含）+ 通用/专业/特定规则
├── SOUL.md     输出风格/性格（核心信念/边界/氛围/连续性 四节）
├── USER.md     用户：稳定章（明确偏好带背景）+ 动态章（协作推断带依据）
├── SECRET.md   凭据（权限 600，不提交 git）
├── TOOLS.md    环境与工具：系统环境（被引用块）+ 操作条目（结果导向）
├── TODO.md     待办 + 当前任务状态
└── memories/   三级记忆：summaries（摘要）→ archive（档案）→ drafts（草稿按任务分文件）
```

## 设计原则

- **最小设计（总纲）**：能用元设计的绝不设计，能用元规则的绝不写规则——给原则不给定案
- **结构即规则**：层级性质承载处理方式——可复用知识进域文件，时间性记录进 memories 三级
- **结果导向**：形式与内容由本质目标决定
- **上下文单一归属 + 引用**：稳定环境/背景信息集中定义，具体记录引用不复制
- **写入自检**：写完问"未来的我能直接理解吗？"
- **防过度解读**：权威级三级（原话/推断/转述），推断只记被确认过的
- **冲突分治**：当前状态类覆盖删除，资产记录类标记替代

## 使用

1. 复制整个目录为你的 `memory/`
2. 按各文件**头部注释**的写作规范填充内容
3. 完整规范见 `AGENTS.md` 元规则章（自包含）

## 文件角色速查

| 文件 | 存什么 | 怎么写（见头部注释） |
|------|--------|---------------------|
| SOUL.md | 风格/性格 | 四节行为准则，无时间戳 |
| USER.md | 用户偏好/协作 | `[日期][权威级] + 背景/依据` |
| SECRET.md | 凭据 | `[日期] 名称：值` + 用途 |
| AGENTS.md | 方法论 | 四级规则，`[日期][权威级] + 源` |
| TOOLS.md | 环境与工具操作知识 | 被引用块 + 操作条目，结果导向 |
| TODO.md | 待办 | 含触发条件 |
| memories/ | 三级记忆 | 草稿→档案→摘要 单向流转 |

## 脱敏说明

本仓库为**纯模板**，不含真实用户偏好、凭据、环境信息——所有真实内容以 `<占位>` 表示，复制后替换。
